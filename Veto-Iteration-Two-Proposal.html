Veto Protocol · Proposal

Iteration Two — Reach Further, Make the Controls Land

Google Workspace and GitHub are live and read-only. This iteration widens what Veto can sit in front of, and turns two existing controls from built into used.

A · Coverage — new connected applications

Same shape as GitHub: narrowest scopes, read-only, one tool per action.

1 Microsoft 365Outlook · OneDrive · SharePoint
Read mail, files and sites, under the same policy engine as Google.
The other half of the market. Google-only closes the door on most enterprises.
 3–4 wks
2 Slackchannels · messages · files
Read channels and threads an agent has been granted.
Often more exposing than Drive — it is where the unguarded conversation happens.
 1–2 wks

B · Control — make what exists actually get used

3 Approval routingSlack · email · push
A step-up approval reaches the person wherever they are, not only the dashboard.
Today a challenge waits on a screen nobody has open, then expires. The control works; the delivery does not.
 4–6 days
4 Policy templatesstarter rules
A dozen sensible rules to start from, instead of an empty policy screen.
Veto denies by default, so a new workspace refuses everything — which looks identical to being broken. This is the gap between signing up and seeing value.
 3–5 days

C · Differentiator

5 Shadow AgentsPro
Finds AI agents touching the company's Google and GitHub accounts without going through Veto at all, by reading the providers' own audit logs and comparing them against Veto's record.
Veto only sees what passes through it. Everything else is invisible today — and the dashboard looks perfectly healthy while it happens.
 1–2 wks
Two things worth stating plainly. Shadow Agents needs Google Workspace admin and GitHub organisation audit-log access — a customer-side prerequisite, not build work, and worth confirming before it is scheduled. Every new integration is also a new trust boundary, so each one re-opens the threat model for review; that review is budgeted inside the estimates above.
Suggested order. Approval routing and policy templates first — both are under a week and both make the product that exists today demonstrably better. Then Shadow Agents, which is the strongest thing to show a buyer. Microsoft 365 last of the five, because it is the largest piece and the one most worth doing unhurried.
